# Stash Radar changelog

## 0.1.0
- First version (Forge + NeoForge, Minecraft 1.21.1).
- Search screen (key K) with item suggestions and range picker; `/find <item> [range]` for everyone.
- Server-side search of chests, trapped chests, barrels and shulker boxes (configurable, modded containers too), including shulker box and bundle items inside them.
- Per-player particle outlines, configurable range, max range, cooldown and permission level.
